  • account deletion requests.

Google Sign-In Help

If you see an error that your email already exists with another sign-in method, sign in using your original method and then contact support if you still cannot access your account.

Location Permission Help

  • Dora requests location only for location-based features (for example map centering and nearby place search).
  • If permission is denied forever, open device app settings and allow location access for Dora.
  • You can continue using Dora without location permission, but nearby/location shortcuts will be limited.

Microphone Permission Help

  • Dora requests microphone permission only for user-initiated capture flows that include audio recording.
  • If microphone permission is denied forever, open device app settings and allow microphone access for Dora.
  • You can continue using Dora without microphone permission, but audio-enabled capture features may be limited.

Account Deletion Support

Preferred path: open Dora and use Settings -> Delete Account.

For account deletion policy and instructions, see: https://doraapp.netlify.app/delete_account.html.
